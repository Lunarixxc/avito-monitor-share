## Запуск и ручное действие

На сервере один раз:

```bash
cd /home/asat/codex-work/avito-monitor
bash research/cdp-linux/start-observation.sh
```

Скрипт сохраняет профиль в `private/manual-profile-before-observation`,
запускает исходный `manual-profile` на about:blank и новый прямой транспорт.
Chrome и транспорт ограничены двумя часами. Повторный запуск защищён claim.
Не восстанавливать прошлые вкладки через предупреждение Chrome.

На компьютере владельца:

```powershell
ssh -N -T -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -L 127.0.0.1:6080:127.0.0.1:6080 asat@192.168.31.176
```

Открыть `http://127.0.0.1:6080/vnc.html?autoconnect=1&resize=scale`.
В удалённом Chrome один раз вручную ввести `https://www.avito.ru/kazan/noutbuki`.
Записать время и последовательность экранов. При временном ограничении дать
сайту до 60 секунд на собственный переход; не нажимать refresh.
Сообщить результат и оставить вкладку открытой. CAPTCHA — только вручную
по решению владельца; автоматических действий с проверкой нет.

После сообщения владельца о результате, на сервере:

```bash
cd /home/asat/codex-work/avito-monitor
.venv/bin/python research/cdp-linux/read_manual.py --manual-ready
sudo journalctl -u avito-observation-direct --no-pager -o cat
```

Reader подключается один раз, без goto/reload, кликов или закрытия Chrome.
Результат: `results/manual-observation/result.json`, права только владельцу.
Сохраняются пять примеров объявлений и безопасные технические поля:
статус/тип/протокол и время текущей загрузки, наличие фрагмента и referrer
без их значений, DOM-count, webdriver, язык, размер окна, часовой пояс.

## Границы измерения

CONNECT-журнал содержит время, укрупнённый домен, порт, этап и класс ошибки.
Путь eno1/mark 0x2024 прежний; allowlist дополнен доменами CAPTCHA. Заголовки, cookies, тела и TLS
не читаются. После открытия туннеля HTTP-ошибки внутрь TLS не отправляются.
Журнал показывает соединения, а не отдельные HTTP-запросы/статусы.
Чтение Navigation Timing после загрузки показывает только текущий документ;
предыдущий экран и его ответ из него восстановить нельзя. Нулевой статус
означает отсутствие доступного измерения, а не успешный ответ.
Transfer size 0 сам по себе не доказывает кеш. HTTP 200 без DOM не успех.
Домен в denied не доказывает, что ресурс необходим для доступа.
Успешное чтение не доказывает возможность автономного обновления.

При необходимости следующим отдельным опытом можно записать цепочку Network
во время ручного открытия; включение DevTools до загрузки само меняет условия.
HAR не собирается: даже очищенный экспорт может содержать чувствительные URL.

отдельный учёт пустого probe. Сеть Avito в тестах не используется.
