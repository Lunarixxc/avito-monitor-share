# Ручной контроль Linux Chrome

**Контроль завершён:** ручная выдача и DOM после attach работали (50 элементов),
один goto через CDP → 429, за 20 секунд выдача не восстановилась.
[Результат](MANUAL-RESULT.md). Серверная сессия остановлена, профиль сохранён.

2026-09-20. Цель: автономный сбор на постоянно включённом Linux-сервере.
Windows используется только для просмотра экрана; успешный Windows CDP-опыт
не означает, что Windows должен стать частью рабочей архитектуры.

## Подготовка

Запускается Google Chrome 153.0.8010.52 под Xvfb с обычной песочницей,
без Playwright, stealth или подмены настроек браузера. Стартовая вкладка about:blank.
CDP включён на 127.0.0.1:9223, клиент ещё не подключается. Профиль новый:
`private/manual-profile`. Профиль предыдущей попытки `private/profile` не меняется.
После ручного успеха CDP должен подключаться именно к этой запущенной сессии.

Используется прежний локальный CONNECT-транспорт 18081 через eno1/mark 0x2024.
Он не меняет TLS, но ограничивает домены: возможное отличие транспорта от Windows
остаётся неустранённым фактором. Глобальная сеть не менялась.

Сервисы временные, Restart=no, предел 7200 секунд. Группа процессов экрана
завершается целиком при остановке. Потеря direct transport останавливает экран,
чтобы не оставлять браузер в среде с неработающей сетью. Профиль сохраняется.
Порты 6080/5901/9223 только loopback. VNC без пароля допустим здесь только через
SSH на доверенном сервере: локальные пользователи сервера также имеют доступ.

## Действия владельца на Windows

Открыть PowerShell:

```powershell
ssh -N -T -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -L 127.0.0.1:6080:127.0.0.1:6080 asat@192.168.31.176
```

Оставить терминал открытым. В обычном Windows-браузере открыть:

`http://127.0.0.1:6080/vnc.html?autoconnect=1&resize=scale`

Внутри удалённого окна Linux Chrome нажать Ctrl+L и вставить:

`https://www.avito.ru/kazan/noutbuki`

Если вставка не передаётся через noVNC, использовать панель Clipboard слева
или набрать адрес вручную. Не вводить его вместо адреса noVNC в браузере Windows.
Не включать Google Sync, не импортировать cookies. Проверить только одну выдачу.

- Если объявления появились: оставить вкладку и профиль открытыми, сообщить
  «На Linux выдача работает». Затем инженер подключит CDP к этой же сессии.
- Если ограничение/CAPTCHA: ничего не обновлять, сообщить текст экрана.
  Автоматического подключения/повторов не выполнять; состояние можно осмотреть
  через уже открытый экран без новой навигации.

## Остановка и безопасная проверка на сервере

```bash
systemctl is-active avito-linux-manual.service avito-research-direct-v2.service
ss -ltn '( sport = :6080 or sport = :5901 or sport = :9223 or sport = :18081 )'
sudo systemctl stop avito-linux-manual.service avito-research-direct-v2.service
```

Последняя команда завершает опыт; профиль не удаляет. Выход из SSH-туннеля
сам по себе серверный Chrome не закрывает. Таймер завершения — страховка,
не расписание запросов и не постоянный мониторинг.
